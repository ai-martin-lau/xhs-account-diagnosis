# xhs-account-diagnosis

**小紅書（RedNote）のプロフィールリンクを渡すだけで、約 30 ページの診断レポートと 90 日改善プランの PDF ができる**

ファイルを読みコマンドを実行できる AI コマンドラインツールならどれでも動きます：Claude Code、Codex CLI、Gemini CLI

[レポートのサンプル](https://xhs.addsum.top/samples) · [制作：Addsum](https://addsum.top/)

</div>

---

ただの分析ダッシュボードではありません。アカウント運営者が本当に知りたいことに答えます。

> 自分のアカウントはどこで詰まっているのか。何を先に直し、何を後に回すのか。この先 90 日、毎週何をすればいいのか。

プロフィールと最新 30 件のノート（本文、いいね・保存・コメント数、すべてのカバー画像と本文画像）を自動で収集し、「6 段階ファネルの断点診断」でいちばん大きく漏れている段階を特定します。決まった順序で改善策を示し、そのままクライアントに渡せる PDF に組版します。

小紅書は中国語のプラットフォームなので、レポートは中国語で書かれます。

## レポートの内容

全 10 部、中国語で約 1.5 万〜2.5 万字：

1. エグゼクティブサマリー：結論、主要課題、優先して直す項目、控えめな 90 日予測
2. 現状分析：基礎データ、コンテンツ路線の振り返り、9 項目の健全度評価、ユーザー像
3. 6 段階の断点診断：表示→クリック、クリック→フォロー、フォロー→DM、DM→成約、成約→リピート。各段階で現状・問題・原因・改善策を記述
4. ジャンルと競合：競争環境、ベンチマーク分析、差別化の機会（エージェントがネット検索できる場合はプラットフォーム規約とトレンドも調査）
5. ポジショニング：ポジショニングの公式、アカウント名とプロフィール文の候補、キャラクター設計、ビジュアル規定
6. コンテンツ戦略：コンテンツ構成、ネタ帳、30 日分の日別スケジュール、制作 SOP
7. 収益化：商品の階層、成約までの導線、DM のトーク例、価格設計の原則
8. 90 日実行計画：3 フェーズそれぞれの行動リストと判断基準、マイルストーン表
9. リスク：プラットフォーム・運営・メンタルの 3 種のリスクと 4 つの緊急時チェックリスト
10. 付録：データ管理表、ツール紹介、タイトル集、よくある質問

実在する 3 アカウントのレポートの抜粋を[サンプルページ](https://xhs.addsum.top/samples)で公開しています（同じ方法論で生成）。

## 方法論

- **まず断点を探す**：欠点を並べるのではなく、ファネルでいちばん大きく漏れている段階を見つけ、そこに力を集中します。
- **直す順序が決まっている**：ポジショニングの統一 → 商品のコンテンツ化 → プロフィールでの受け皿 → ビジュアルの統一 → 検索対策 → 収益化テスト。受け皿ができる前にカバーを磨いたり露出を増やしたりしても、来た人を逃すだけです。
- **課題は必ず 4 点セット**：症状、原因、影響、解決の方向。どれかが欠けたら診断ではなくただの不満です。
- **見えるデータだけを使う**：レポートの数字はすべて、スクリプトが作るデータファクト表から取ります。管理画面の表示回数、プロフィール訪問数、DM 数、成約数は取得できないため、その旨を明記し、予測はすべて控えめな幅で示します。
- **結果を約束しない**：「フォロワーや収入は保証できない」とはっきり答える項目があり、90 日の間に本当にコントロールできることを列挙します。

ルールの全文は [`RUN.md`](RUN.md)、レポートの骨組みは [`references/report-template.md`](references/report-template.md) にあります。

## 事前準備

1. Chrome が入ったパソコン（Mac、Windows、Linux）
2. 普段使いの Chrome で小紅書のウェブ版（xiaohongshu.com）にログイン済み
3. Node.js 22 以上（`node -v` で確認）
4. 任意の AI コマンドラインツール：Claude Code、Codex CLI、Gemini CLI など

API キーもほかの依存関係も不要です。

## 使い方

まず対象アカウントのプロフィールリンクを用意します。小紅書アプリでプロフィールを開き、右上の共有から「リンクをコピー」を選ぶか、パソコンのブラウザでプロフィールを開いてアドレスバーをコピーします。形式は `https://www.xiaohongshu.com/user/profile/xxxx` です。

Claude Code では：

```text
诊断这个小红书账号 https://www.xiaohongshu.com/user/profile/xxxx
```

Codex CLI、Gemini CLI などでは：

```text
<クローン先>/RUN.md を読み、その手順どおりに実行してください。対象アカウント：https://www.xiaohongshu.com/user/profile/xxxx
```

あとは待つだけです。データ収集に約 5 分、レポート作成に約 10〜20 分かかり、操作は不要です。

## 出力されるもの

現在の作業ディレクトリに `账号诊断/<アカウント名>/` が作られます：

- `<アカウント名>_小红书账号诊断报告与优化方案.pdf`：納品用の PDF
- 同名の `.md`：編集できるソース
- `证据/`（エビデンス）：プロフィールのスクリーンショット、すべてのカバー画像と本文画像、元データ `data.json`、データファクト表

## 途中で出るかもしれない表示

- **Chrome に「リモートデバッグを許可」と出る**：許可を押してください。スクリプトがあなたの Chrome につなぎ、ログイン状態のまま閲覧するためです。
- **「Chrome を完全に終了してから再試行」と出る**：Mac は Cmd+Q、Windows はすべての Chrome ウィンドウを閉じ、同じ文をもう一度送ります。Chrome は自動で再起動します。
- **ログイン画面が出る**：Chrome で小紅書のウェブ版に一度ログインし、続行させます。
- **遅く感じる**：通常の閲覧に近づけるため、わざとゆっくりアクセスしています。

## よくある質問

**自分の小紅書アカウントに何かしますか？**
しません。読むだけで、いいね・フォロー・コメント・DM は一切行いません。人と同じように公開プロフィールを閲覧します。アクセスの速度は抑えていますが、自動アクセスにはプラットフォームのリスク管理に引っかかるわずかな可能性があります。気になる場合は使わないでください。

**他人のアカウントも診断できますか？**
プロフィールが公開されていればできます。自分のアカウント、または許可を得たクライアントのアカウントにだけ使ってください。

**フォロワー増加は保証されますか？**
されません。レポート自体もそうした約束はしません。示すのは断点、直す順序、90 日の計画で、結果は実行しだいです。

**一度に何アカウントまで？**
一度に 1 つです。終わったら次のリンクを送ってください。
