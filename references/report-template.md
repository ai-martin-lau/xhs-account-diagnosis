# 报告骨架模板（十部分）

标题格式：《小红书账号诊断报告 & 优化方案》。以下每节给出结构要求和写法要点。模板里的示例多取自 AI 产品账号，所有示例都要替换成目标账号的真实业务语境，不要照抄。

## 封面基础信息

客户名称 / 账号名称 / 服务区域 / 所属行业 / 核心产品或服务 / 服务周期（默认90天）/ 报告版本 / 数据采集时间（取数据事实表）/ 制定日期。

紧接一段顾问开场信：直呼客户，先用主页可见数据客观描述现状（"X个粉丝、Y次获赞与收藏，账号现状确实……"），再指出数据里真实存在的积极信号，然后点破核心矛盾（通常形如"真正的问题不是没有流量，而是用户看完仍然不清楚：你到底做什么 / 谁该关注你 / 关注后持续获得什么 / 你和同类账号有什么不同 / 在哪里体验你的产品或服务"）。最后一句话说清本次诊断解决的三件事：找断点、把优势翻译成内容、建立90天执行路径。

## 核心问题优先级表 + 优先修复项（放目录前，方便客户先看结论）

表格列：优先级（P0/P1/P2）/ 核心问题 / 具体表现 / 对业务的影响。通常 P0 三条、P1 三到四条、P2 两条。

优先修复项：三个最先要做的动作（通常是：定位收窄、把"我懂X"改成"我能帮你完成什么任务"、搭主页承接），然后给修复顺序链：定位统一 → 内容主角化 → 主页承接 → 视觉统一 → 搜索布局 → 商业化测试，并解释为什么不先修封面。

## 第一部分 执行摘要

- **1.1 诊断结论速览**："这个账号最大的优势不是A，也不是B，而是C"。列出该赛道大多数账号在做的3至4种同质化内容，指出目标账号具备的稀缺条件，宣告账号应从什么定位转向什么定位，并给出"账号最终要形成的认知不是X，而是Y"。
- **1.2 核心问题清单**：4至5个问题，每个都是四件套（表现/原因/影响/解决方向），问题标题用"陈述句反差"写法（如"信息很多，但核心价值不明确"）。
- **1.3 优先修复项**：P0/P1/P2 三组任务清单，P0 是第一周必须做完的具体动作。
- **1.4 90天目标预测**：表格列（阶段/粉丝增长预测/有效咨询/体验或到店人数/收入预测/核心能力成长），按启动期1-30天、优化期31-60天、增长期61-90天、90天累计四行。全部给保守区间，表格前后声明估算前提（当前粉丝基数、发布频率假设、承接是否建成），并说明收入预测成立的前提条件。

## 第二部分 账号现状深度分析

- **2.1 基础数据盘点**：表格列（项目/当前情况/顾问判断），逐项过：账号名、粉丝数、获赞与收藏、关注数、IP属地、头像、背景图、简介、当前内容展示方式、内容风格。每行"顾问判断"必须下明确结论。表后声明缺失的后台数据及其影响。
- **2.2 内容历史复盘**：归纳账号正在走的2至3条内容路线，各自的优势和问题。核心论点通常是"知识/资讯类内容能被收藏但不产生依赖；业务类内容离钱近但呈现像说明书"。给一组错误表达 vs 正确表达的对照实例（用该账号的真实产品/服务改写）。
- **2.3 账号健康度评估**：9维评分表（业务潜力/赛道空间/定位清晰度/内容差异化/视觉识别度/信任体系/搜索能力/转化承接力/综合健康度），每维 X/100 加一句判断。表前声明"顾问主观评估，不等于平台后台评分"。最后给核心判断（一句话概括账号的结构性问题，如"业务能力强于运营表现"）。
- **2.4 用户画像推断**：2至3类核心用户（年龄/城市/职业/需求/痛点/付费倾向），加一节"暂不作为主目标的人群"并解释为什么（有流量无业务价值）。

## 第三部分 六环节断点诊断（方法论核心）

六环节：曝光→点击、点击→关注、关注→私信、私信→转化、转化→复购/转介绍。按业务形态可把"私信"替换为评论咨询、进店、加群等实际承接动作。

每一环节固定四段：**当前现状 / 问题诊断 / 具体原因（列表，3至5条）/ 优化方向（给可直接抄的实例：标题怎么改、封面放什么、置顶写什么、私信怎么回）**。

- 曝光→点击：核心通常是"封面标题讲知识/讲产品名，不讲用户任务和结果"。优化方向给5个按"用户任务+结果"重写的标题实例。
- 点击→关注：核心通常是"账号缺一个稳定承诺"。列出用户可能对账号产生的几种错误归类，给一句话关注理由，规定主页前三篇置顶要回答的三个问题。
- 关注→私信：给"三问式承接"（你要解决什么问题/卡在哪一步/使用频率），和主页产品（服务）地图的分类方式。
- 私信→转化：先重新定义转化的四层（进入体验/完成第一次任务/再次使用/付费），指出只看下载量或访问量会高估价值，然后为每个产品或服务明确一个"核心激活动作"（表格）。
- 转化→复购/转介绍：给四种留存机制（持续更新/场景模板/用户案例/结果自带分享属性），强调转介绍来自"结果好到自然想发给别人"而不是求转发。
- **3.6 断点优先级排序**：表格（排名/断点/严重程度/修复时点）。

## 第四部分 赛道与竞品分析

- **4.1 赛道概况**：用户需求正在从什么转向什么（通常是从"是什么"转向"能不能帮我完成"），指出长期有价值内容的三特征：有具体场景、有真实结果、有自己的方法或产品。
- **4.2 竞争格局**：按账号类型分4至5类（而不是点名具体账号），每类列优势和弱点。
- **4.3 对标账号拆解**：表格（对标类型/值得学习/不建议复制）。没有客户提供对标名单时按类型写，不虚构具体账号。
- **4.4 差异化机会点**：3至4条差异，每条一句话定性加一段展开。最后一条通常是"实力强但表达克制"：列出让用户自己得出结论的证据清单。

## 第五部分 IP定位方案

- **5.1 定位公式**：完整版（面向〈人群〉，依托〈稀缺资产〉，持续〈动作〉，帮用户〈收益〉）+ 一句话定位 + 用户关注理由 + 推荐账号名（优先方案1个、备选3至4个，并评价现有名字）。
- **5.2 人设设计**：核心人设一句话、人设关键词6至8个、**不建议的人设方向**（列出会引发距离感或信任反噬的标签）、人设表达方式（给"不要说X，更有效的是讲Y"的对照，Y 通常是带取舍细节的过程叙述）。
- **5.3 风格调性**：内容语气清单、推荐表达5句（该账号语境的原话）、禁止表达清单（一键解决/完全替代/全网最强/100%/保证XX等）。
- **5.4 视觉规范**：头像建议（给3个梯度选项）、背景图建议（具体到三行文案怎么排）、简介推荐3个版本（产品型/团队型/强记忆型，每版3至4行可直接粘贴）、封面三模板（A结果演示/B痛点场景/C幕后日志，各给结构：上方小字+中间大标题+下方元素）、色彩建议（主色/辅助色/强调色，每张封面2至3色）。

## 第六部分 内容策略规划

- **6.1 内容类型矩阵**：表格（内容主线/主要目的/建议占比/建议频率），5条主线占比合计100%，通常：核心业务实测35%、目标人群场景25%、幕后日志15%、行业认知15%、用户案例10%。说明前30天不建议发什么。
- **6.2 选题方向库**：按业务方向分4至5类，每类8至10个具体选题，全部用该账号的真实产品/服务写，标题符合第六部分SOP的结构。
- **6.3 30天逐日排期**：Day 1 到 Day 30，每天三行（内容方向/具体选题/目的）。固定节奏：Day1 定位宣言、Day2 产品或服务地图、Day7/14/21 周复盘、Day30 月度复盘，中间按内容矩阵轮转，分批测试不同人群方向。
- **6.4 内容生产SOP**：
  - 标题：必须含"人群/场景/任务/结果"四类信息中至少两类，给5种结构（任务+结果 / 痛点+反差 / 行为+收益 / 真实测试 / 取舍判断）各配该账号的实例。
  - 开头：前三行让用户确认"这与我有关"，给推荐开头和不推荐开头（"随着XX的快速发展"式一律禁止）各一例。
  - 正文：五段式（具体场景/原来的做法/操作过程/输出结果/适用范围和限制），并列出业务内容必答的七问（输入什么/什么步骤/输出什么/用时多久/人工还做什么/谁适合/谁不适合）。
  - 结尾：不强行引导互动，用"适合谁+边界声明"收尾。
  - 搜索词：每篇1主词+2至3辅词+1人群场景词，按业务方向给3至4组关键词库，外加人群与地域词组；地域词只出现在20%至30%的内容里，不生硬。

## 第七部分 变现路径设计

- **7.1 产品/服务层级**：五层（免费体验 / 低价验证19-49元 / 订阅或Pro / 组合包199-499元 / 企业或高客单定制3000元起），每层列包含什么、承担什么任务。价格按行业调整，逻辑不变：免费拉新验证 → 低价测付费意愿 → 订阅收稳定性 → 组合提客单 → 定制吃深度。
- **7.2 转化路径**：标准转化链路（内容→主页→置顶地图→免费体验→完成首次任务→回访→复用→升级），加置顶三件套的标题和内容要点（置顶一账号介绍/置顶二产品或服务地图/置顶三新用户指南）。
- **7.3 私信话术**：先声明合规（平台规则内承接、不批量发外部联系方式）。给第一次回复的三问分流、按用户类型的2至3组分流话术、使用后回访话术、付费升级说明话术（"如果每周都用，Pro更合适；偶尔用，免费版就够了"式的反推销表达）。
- **7.4 定价原则**：四条（免费解决第一次成功 / 为效率和稳定性收费而不是为概念收费 / 前45天不急于高价变现 / 免费与付费必须有清晰边界），最后给免费版vs付费版边界对照表。

## 第八部分 90天执行计划

三阶段各四段：时间 / 核心目标 / 执行动作（10条左右具体到可打勾）/ 阶段判断标准（不是看爆款，而是回答几个结构性问题）。

- 启动期1-30天：定位统一、主页重构、内容模板、种子用户、找最强需求方向。
- 优化期31-60天：砍弱放强、优化激活、建案例、测低价付费。
- 增长期61-90天：聚焦一个主产品/主服务、放大搜索、免费到付费自然升级、探索高客单。

**8.4 里程碑与验收标准**：表格（时间节点/核心里程碑/验收标准），第7/14/30/45/60/75/90天各一行。

## 第九部分 风险预警与应对

- **9.1 平台风险**：违规导流表达、效果承诺过度、标签错位（简介里与主业无关又有合规风险的标签建议删除）、用户数据与隐私。每条配应对方式。
- **9.2 运营风险**：业务线铺太多（给主次结构建议和"第31天按数据定主线"的规则）、内容更新依赖业务进度（给一个业务至少拆出10至20篇内容的拆解清单）、免费用户服务成本（FAQ库+边界）。
- **9.3 心态风险**：被泛流量爆款带偏（给"一篇内容是否值得继续"的五指标：主页访问/新增关注/咨询/体验人数/真实反馈）、过度追求完美不上线、"免费等于没有商业价值"的误区纠正。
- **9.4 应急预案**：四种情况各给检查清单：连续10篇数据偏低 / 体验人数高但留存低 / 有流量但没有业务用户 / 付费无人购买（先别降价，先查五件事）。

## 第十部分 附录

- **10.1 数据监控表模板**：内容数据表、业务数据表、用户反馈表的列名，加每周复盘七问。
- **10.2 工具推荐**：内容策划/视觉设计/视频制作/素材归档四组，素材归档给五个固定文件夹名。
- **10.3 爆款标题库**：四类（业务演示/认知反差/幕后日志/搜索流量）各6至8条，全部用该账号语境写。
- **10.4 常见问题解答**：8问左右，必含：能不能保证结果（答不能，并给90天真正可控清单）、没效果怎么办（按断点逐层排查而不是多发）、每天投入多少时间、不会拍视频怎么办、没案例怎么办（列7种前期案例替代来源，强调标注测试性质）、免费怎么赚钱、方向会不会太杂（30天测试后按数据收敛）、要不要反复强调实力背景（不要，列用户真正相信的五件事）。

## 最终结论 + 交付说明

最终结论：先说账号不缺什么（内容/产品/实力），点出真正缺的是"把它们连起来的表达与转化系统"；给出"从X转向Y"的一句话转变；描述90天后要形成的用户认知（"想找XX，会想到XX"）。

交付说明：报告基于哪些可见信息制定、列出全部未取得的后台数据、声明预测为保守估算、约定第7/14/30/60/90天复盘节点。
