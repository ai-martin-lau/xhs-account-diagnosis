# xhs-account-diagnosis

**Give it a Xiaohongshu (RedNote) profile link, get a 30-page diagnosis and 90-day growth plan as a PDF**

Works with any AI command-line agent that can read files and run commands: Claude Code, Codex CLI, Gemini CLI

[Sample reports](https://xhs.addsum.top/samples) · [Made by Addsum](https://addsum.top/)

This is not another analytics dashboard. It answers the question account owners actually have:

> Where is my account stuck? What should I fix first, and what comes after? What do I do each week for the next 90 days?

It collects the profile and the latest 30 notes (text, likes, saves, comments, every cover and inner image), runs a "six-stage funnel breakpoint" diagnosis to find the stage that leaks the most, lays out fixes in a fixed order, and typesets everything into a PDF you can hand to a client.

The report is written in Chinese, since Xiaohongshu is a Chinese-language platform.

## What the report covers

Ten parts, roughly 15,000 to 25,000 Chinese characters:

1. Executive summary: verdict, core problems, priority fixes, a conservative 90-day forecast
2. Current state: baseline data, content-line review, a nine-dimension health score, audience personas
3. Six-stage breakpoint diagnosis: impression to click, click to follow, follow to DM, DM to conversion, conversion to repeat. Each stage gets current state, problem, causes and fixes
4. Niche and competitors: landscape, benchmark breakdown, differentiation (platform rules and niche trends are researched when the agent has web access)
5. Positioning: positioning formula, name and bio options, persona, visual guidelines
6. Content strategy: content mix, topic bank, a day-by-day 30-day calendar, a production SOP
7. Monetization: product tiers, conversion path, DM scripts, pricing principles
8. 90-day plan: three phases with action lists and checkpoints, plus a milestone table
9. Risks: platform, operational and mindset risks, with four contingency checklists
10. Appendix: tracking sheets, tools, a headline bank, FAQ

See excerpts from three real accounts on the [sample page](https://xhs.addsum.top/samples) (same methodology).

## Methodology

- **Find the breakpoint first.** Instead of listing every flaw, find the funnel stage that leaks the most and put the effort there.
- **Fix in order.** Positioning → product-as-content → profile conversion → visual consistency → search → monetization tests. Polishing covers or buying reach before the profile can convert just wastes the traffic.
- **Every problem has four parts.** Symptom, cause, impact, fix. Anything less is a complaint, not a diagnosis.
- **Only visible data.** Every number in the report comes from a fact sheet generated by the scripts. Back-end impressions, profile visits, DMs and conversions are not available, the report says so, and every forecast is a conservative range.
- **No guaranteed results.** The report states plainly that it cannot promise followers or income, and lists what is actually within your control over 90 days.

The full rules are in [`RUN.md`](RUN.md); the report skeleton is in [`references/report-template.md`](references/report-template.md).

## Requirements

1. A computer (Mac, Windows or Linux) with Chrome
2. Signed in to the Xiaohongshu website (xiaohongshu.com) in your everyday Chrome
3. Node.js 22 or later (check with `node -v`)
4. Any AI command-line agent: Claude Code, Codex CLI, Gemini CLI and so on

No API key and no other dependencies.

## Usage

First get the profile link: in the Xiaohongshu app, open the profile, tap share and choose "Copy link"; or open the profile in a desktop browser and copy the address, which looks like `https://www.xiaohongshu.com/user/profile/xxxx`.

In Claude Code, say:

```text
诊断这个小红书账号 https://www.xiaohongshu.com/user/profile/xxxx
```

In Codex CLI, Gemini CLI or another agent, say:

```text
Read <clone path>/RUN.md and follow it exactly. Target account: https://www.xiaohongshu.com/user/profile/xxxx
```

Then wait. Collecting data takes about 5 minutes and writing the report about 10 to 20 minutes, with no input needed.

## What you get

A folder `账号诊断/<account name>/` in the current working directory:

- `<account name>_小红书账号诊断报告与优化方案.pdf`: the PDF to deliver
- The matching `.md`: the editable source
- `证据/` (evidence): profile screenshot, every cover and inner image, raw `data.json` and the fact sheet

## Prompts you may see

- **Chrome asks to "Allow remote debugging"**: click Allow. The script connects to your Chrome so it can browse with your login.
- **"Quit Chrome completely and retry"**: press Cmd+Q on Mac or close every Chrome window on Windows, then say the same sentence again. It reopens Chrome by itself.
- **A login wall**: sign in to the Xiaohongshu website once in Chrome, then let it continue.
- **It seems slow**: the pace is deliberately slow to look like normal browsing.

## FAQ

**Will it touch my Xiaohongshu account?**
No. It only reads: no likes, follows, comments or DMs. It browses public profiles the way a person would. The pace is throttled, but any automated access carries a small chance of triggering the platform's risk controls. Do not use it if that concerns you.

**Can I diagnose someone else's account?**
Yes, as long as the profile is public. Please use it only on your own accounts or on client accounts you are authorized to analyze.

**Does the report guarantee growth?**
No, and the report says so itself. It gives you the breakpoint, the fix order and a 90-day plan. Results depend on execution.

**How many accounts at once?**
One at a time. When one is done, send it the next link.
